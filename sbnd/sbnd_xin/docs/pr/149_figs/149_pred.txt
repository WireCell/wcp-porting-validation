  - N_max*N_min <= 2500 for >= 99.0 % of blobs in every theta_drift bin, ISO included, on all four samples

4. Q1 METRICS  (per event unless stated; computed identically on every arm by pr149_metrics.py)
   M1 cloud     steiner points of the main cluster (calib steiner[] rows with cluster_id == main)
   M2 zig-zag   per main-cluster segment with length >= 10 cm and >= 10 points, pr/73 definitions on the
                fitted points: ratio = path/chord; rms_dr = rms distance of the points from the chord,
                projected on the drift axis; fold = fraction of interior turns > 30 deg.
                Event value = length-weighted mean over those segments.
   M3 coverage  uncov = sum(charge in main-cluster T_proj_data cells with charge_pred < 0.1*charge)
                        / sum(charge in those cells)          (cell set is readout-only => same denominator)
   M4 structure n_seg (main cluster), n_stub = main-cluster segments shorter than 3 cm with an endpoint
                vertex of degree 1
   M5 vertex    distance of main_vertex to the vtx105 hand click; fixed denominator = every labelled
                event of the stage; an arm with no calib dump / no main vertex on a labelled event scores
                that event as a FAILURE (distance = inf).  Report n(<=1 cm), n(<=3 cm), and per-event
                movers: toward (closer by > 1 cm), away (farther by > 1 cm).  pr90_movers.py is run too.
   M6 owner cases: M2/M3/M4/M5 per case, before/after, one-line reading each.

   Q1 READING (stated before seeing numbers): "ISO PR improves" for an arm X vs s0 iff, on the ISO stratum
   (Stage 1 ISO events for Stage 1; Stage 2 ISO set for Stage 2):
     (a) median per-event delta rms_dr < 0 AND median delta ratio <= 0, AND
     (b) median per-event delta uncov < 0, AND
     (c) vertex: toward > away on the labelled ISO events, AND n(<=3 cm) does not fall, AND
     (d) n_stub summed over the stratum rises by no more than max(2, 10 % of the stratum's events).
   Partial (a/b pass, c or d fail) is reported as "trajectory improves, PR does not follow".
   The same numbers on the non-ISO control are reported beside it; an effect equal on both strata is
   not ISO-specific and is said so.
