# WHY THIS FILE EXISTS.  Every retire round writes its own dated driver
# (retire_20260730.sh, _20260802.sh, _20260803.sh), each with its own inline
# PROTECTED="..." string.  Nothing carries forward automatically: an arm named
# in one round's list is invisible to the next unless a human retypes it.  Doc
# pr/28 sec.15.9 flagged that for work-tfix388-r9 and it has been carried by
# memory ever since.  This file is the carry-forward list -- a new round's
# driver must union its inline PROTECTED with every line below.
#
# It does NOT retire anything and is not executable.  Removing a line is a
# decision to let that arm be swept; make it deliberately, and never remove one
# because a doc "already has the numbers" -- CLAUDE.md M13 protects the record
# itself, not just the summary of it.
#
# Format: <arm>  TAB  why it must survive  TAB  who cites it
# Field 1 may hold SEVERAL whitespace-separated arm names (the vf37 lines did).
# Housekeeping: when an arm is genuinely superseded, move its line to the
# RETIRED section at the bottom with the date, do not delete it.
