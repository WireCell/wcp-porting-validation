## What was built

`wclsTensorSetLabeler` (larwirecell `aiml/TensorSetLabeler.{h,cxx}`, lib
`WireCellAIML`; `wcls::IArtEventVisitor` + `ITensorSetFilter` + `ITerminal`)
sits between the all-APA `MultiAlgBlobClustering` and its `TensorFileSink`:

- **Event metadata** into the tensor-set md: run/subrun/event +
  `nu_pdg/nu_ccnc/nu_int_type/nu_energy/nu_vtx_{x,y,z}/nu_flavor`.
- **`truth_per_track`** `[ntracks x 22]` tensor: beam-nu primaries (default),
  with a `nu_idx` column identifying the interaction (rockbox = multiple
  beam-nu vertices/event).
- **Per-blob `trackid`** in the live blob `scalar` PC: SimEnergyDeposit
  (`ionandscint:priorSCE`) → blob association in raw coords, with SCE
  true→reco shift + diffusion smearing + `abs(TrackID)` (see below).
- **Bee debug sets** (shared mabc.zip): `truth_trackid_labeled`,
  `truth_unlabeled`, `truth_depo_sce`, and a per-interaction `{i}-mc.json`
  particle-flow tree.

WCT side (branch `tgm`): added `trackid` (default -1) to the blob scalar PC
(`aux/SamplingHelpers` + doctest + PatternDebugIO); the `truth_labeler`
option in `sbnd/clus.jsonnet` (builds the labeler pnode, adds `sce_field_fwd`,
flips the sink's `dump_mode` off so tensors are written); `n_sample_truth_depo_sce`.

## The five problems solved (in order), each verified on BEE

1. **Baseline** point-depo association (tick + 3-wire bounds, ±slop): ~58%
   of blobs labeled on evt 32/10/6.
2. **SCE** (`depo-blob-smearing.md §2/§3.2`): priorSCE depos are TRUE
   positions, blobs are post-SCE.  Shift depos true→reco with a 2nd
   `SCEFieldTH3` (`TrueFwd_Displacement_*`, `sign:1`) — the dualmap file has
   both directions.  → 67%.
3. **Diffusion smearing**: each depo is a Gaussian ball, drift diffusion
   (DL=4.0/DT=8.8 cm²/s, `wcsimsp_sbnd.fcl`) ⊕ SP-filter smearing
   (`Gaus_wide` 0.10 MHz → 3.18 ticks; `Wire_ind`/`Wire_col` k=1.05/3.60 →
   0.269/0.078 pitch, `sp-filters.jsonnet` via dunereco smear-dnn-campaign).
   Acceptance = bounds ± (slop + nsigma·σ).  → 82%.
4. **abs(TrackID)** (CRITICAL, `TensorSetLabeler-notes.md §2.1`): larg4 marks
   deposits of DROPPED descendants (delta rays) with the NEGATIVE ancestor
   trackid.  Treating tid<0 as unlabeled STRIPED real muon tracks (found in
   evt 32/10/13 red-box track).  Fold with `abs()`.  → 82/53/47/68% became
   97/74/59/80% on 4 events; NN-coherence 100%.
5. **Beam-nu truth selection + nu grouping**: `truth_per_track` keeps beam-nu
   primaries (assns MCTruth `Origin()==kBeamNeutrino` + `Process()=="primary"`,
   larreco CellTree "nuOnly"; NOT product-id compare — rockbox has multiple
   beam-nu MCTruths).  The `mc.json` tree groups particles under a
   per-interaction "initial mother neutrino" root (id `9000000+nu_idx`,
   start=end=vertex, name/KE from the MCTruth neutrino).  `pf_nu_only`
   (default true) drops all cosmics from the tree.

Final 10-event validation: blobs labeled 59–97%/event, NN-coherence ≥99.6%
(100% on 8/10); unlabeled remainder = real ghosts (isochronous tracks).

## Why trackids are offset by 1e7/2e7

SBND G4 runs TWO Geant4 instances (`larg4intime`/`larg4outtime`);
`MergeSimSources` (`mergesimsources_sbnd.fcl`,
`TrackIDOffsets: [10000000, 20000000]`) merges them into `largeant`, adding
the per-source offset to every track AND mother id.  The block encodes the
SIMULATION INSTANCE, not the generator — an in-time cosmic sits in the 1e7
block next to GENIE tracks.  This is why `Mother()==0` finds no primaries
(use `Process()=="primary"`) and why provenance needs the MCTruth Assns.

## Gotchas hit this session (all in the pitfalls/build docs now)

- **miniz.h** not installed by `wcb install` → hand-copy into `opt/include`.
- **-Werror**: dangling ref on `face->sensitive().bounds()`; ctor init-list
  order (`-Werror=reorder`).
- **Stale-.so**: a failed larwirecell build + blind copy ran OLD code and
  produced misleading "results" — always check the build exit status.
- **make install prefix** `/usr/local` (read-only) can fail the install step
  AFTER a good compile; libs land in `$MRB_BUILDDIR/larwirecell/lib/` — copy
  from there (see doc 0's added caveats).
- **cmake not on PATH** in the mrb env; force a reconfigure via the cached
  `CMAKE_COMMAND` path or by touching a CMakeLists.txt.
- **truth_depo_sce** drifted x blows up (|x|~km) for far-out-of-time
  radiologicals → clip to the `nticks` readout window.
