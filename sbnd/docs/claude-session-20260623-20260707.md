host.  The generic wrapper is
`/exp/sbnd/app/users/yuhw/claude-utilities/in-gpvm-sl7.sh`, but note its default

inside the container instead:

```bash

source /nashome/y/yuhw/.bashrc >/dev/null 2>&1
source /exp/sbnd/app/users/yuhw/wcp-porting-img/sbnd/setup-local-opt.sh >/dev/null 2>&1

./wcb -j16 --notests install

```

- `-j16` is fine on the build nodes; full rebuild ≈ 5 min, incremental ≈ 3 min.
- `install` puts libs into `/exp/sbnd/app/users/yuhw/opt` (what the run setup
  loads).  Build-without-install leaves opt stale → undefined-symbol/vtable
  errors at plugin load (seen with `Bee::Points`); always `install`.
- Verify a new factory landed:
  `nm -DC opt/lib/libWireCellClus.so | grep TaggerCheckTGM`.

## Key gotchas learned this session

- **SCE sign**: the SBND dualmap holds the TrueBkwd (reco→true) offset;
  `SCEFieldTH3` default `sign=-1` makes `forward` SUBTRACT it (wrong).  The cfg
  sets `sign: 1` so `forward = x_t0 + disp` = true position.  The
  `SCECorrection` constructor logs probe displacements — check them.
- **Scope machinery**: `switch_scope(correction_name=...)` always applies the
  transform's `forward` from raw `{x,y,z}` with the cluster flash t0, and sets
  the output scope (e.g. `x_sce`) as default — the whole downstream pipeline
  (clustering, taggers, Bee) then works in that scope.  TaggerCheckTGM
  box-tests scope points directly (no SCE of its own).
- **Bee set filters**: `filter:1` keeps only clusters with
  `get_scope_filter(scope)==true` (≥1 blob SCE-corrects into the active
  volume); default-false for unmarked clusters.  `charge_array` on a bee set
  additionally restricts to clusters carrying that array and overrides q.
- **git remotes**: in wire-cell-toolkit, `origin` = WireCell (official),
  `fork` = HaiwangYu.  TGM work is on `origin/tgm`.  This repo
  (wcp-porting-validation) commits directly to `origin/main`.
