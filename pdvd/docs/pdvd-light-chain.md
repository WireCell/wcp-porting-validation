# PDVD light reconstruction — WCT C++ chain (raw → OpDecon → OpHit → OpFlash)

The Wire-Cell toolkit chain assembled from the milestone results
(`pdvd-spe-template.md` templates, `pdvd-light-filter.md` Wiener-inspired filter,
`pdvd-flash-dt.md` 1 µs coincidence). One `wire-cell` processing reconstructs all
40 OpDets (51 DAPHNE channels) of an event and writes the opflash tensor archive
that Q/L matching will consume. **No QLMatching yet** — this chain ends at OpFlash.

> Job: `pdvd/wct-light-reco.jsonnet`, driver `pdvd/run_light_evt.sh` /
> `run_light_all.sh` (batch). Validation job: `wct-light-frames.jsonnet` +
> `pd_plot/wct_wi_validate.py`. Toolkit pieces: `root/PDVDOpWaveformSource`,
> `flash/OpDecon` (`wiener_inspired` mode), `flash/OpFlashFinder`
> (`channel_map_file`), cfg `pgrapher/experiment/protodunevd/flash.jsonnet` +
> `pdvd-spe-templates.json` / `pdvd-opdet-geom.json` / `pdvd-opch-map.json`
> (generated by `pd_plot/make_light_json.py`).

## Chain topology

```
np02vd_raw_run*_rawwf.root (flat raw_waveform TTree, one entry per waveform)
 ├─ cathode  (opch 10xx, full streams 468800/468864 @16ns):
 │    PDVDOpWaveformSource → OpDecon(WI σ=1.25 MHz, samples=468864)
 │    → OpRoi → OpHitFinder(3.7, intag=decon_roi, fixed_ped_sigma=0.75)
 ├─ membrane (opch 20xx, 1024-tick snippets):
 │    PDVDOpWaveformSource → OpDecon(WI σ=1.0) → OpHitFinder(4.0)
 └─ PMT      (opch 30xx, 1024-tick snippets):
      PDVDOpWaveformSource → OpDecon(WI σ=3.5) → OpHitFinder(2.2)
   → OpHitMerge(3) → OpFlashFinder(nchan=40, bin_width=1µs, opch→opdet map)
   → work/<RUN>_light<EVT>/opflash_pdvd-wct.tar.gz
```

Three instances of the source read the same file with `opch_lo/hi` population
selection; each independently computes the **same tick origin** t0 = the event's
earliest record start over ALL channels (full stream starts at its `timestamp`;
a snippet's sample 64 (`trig_sample`) is at its `timestamp`; µs → ticks is exact
in double). OpHit times are therefore directly coincident across branches, and
flash times are ns relative to t0.

## Key conventions and knobs

| item | value | why |
|---|---|---|
| deconvolution | **wiener-inspired**: `G = conj(H)F/(|H|²+ε)`, `F = exp(−½(f/σ)²)`, F(0)=1 | PE normalization exact and filter-independent; AutoScale/`fixed_snr` unused; post-filter off (`pdvd-light-filter.md`) |
| σ per branch | cathode 1.25 / membrane 1.0 / PMT 3.5 MHz, p=2 | real-noise scan winners; one membrane branch (σ=1.0 doubles top-wall significance and improves bottom) |
| templates | per-DAPHNE-channel, 410 samples, peak@10, raw ADC; 9 pop-avg fallbacks | data-driven templates win 0.4–1.2 % (`pdvd-spe-template.md`); **all 51 channels kept** incl. ch2020 (nonlinear undershoot → amplitude-dependent PE bias, documented not masked) |
| polarity / samples | `input_polarity +1`; snippets 1024, cathode 468864 | jjo extraction positive-going; 468800-sample records zero-padded benignly by OpDecon |
| channel granularity | traces/ophits carry DAPHNE opch; `OpFlashFinder channel_map_file` gangs to 40 OpDet PE columns | templates are per DAPHNE channel; XAs have 2 ch/OpDet; output `ophits` keeps original opch |
| hit thresholds (×100) | cathode 3.7, membrane 4.0, PMT 2.2 | ≈5σ of the WI decon floors; membrane pinned by the noisier top wall (bottom ≈10σ) |
| OpRoi | PDHD-tuned defaults, `veto_sigma` 0.1 | works as-is on 039252/039253/039349; re-derive from the PDVD floor if cathode channels ever ring |
| flash | `bin_width` 1000 ns, `group_by_side=false`, `flash_refine=false`, `remove_late_light` on | single all-PD flash (`pdvd-flash-dt.md`); side split + refine y/z grid are PDHD horizontal-drift assumptions |
| quality cuts | `min_fired_pds 2`, `min_total_pe 10`, `min_fired_pe 1.0` | 40-PD rescale of PDHD's 5/20/1.0 on 160 |
| saturation | detect+veto on, rail 16383, pad 1024 | DAPHNE 14-bit, PDHD-identical machinery |
| `offset_us` | **0 (provisional)** | light↔charge offset not yet calibrated; flash times are relative to the event's earliest light record |

## Validation (all against the standalone python chain)

1. **Decon closure, C++ vs float64 python mirror** (`wct_wi_validate.py`; same
   template JSON, nped=20, ε=(10⁻³·max|H|)², no post-filter): run 039252 evt
   298567 — PMT 650 records max rel diff **1.1e-6**, membrane 1471 records
   **3.1e-7**, cathode 16 streams **2.6e-7** (float32-template limited; same
   level as the PDHD port validation).
2. **Flash-level vs python coincidence clusters** (`flash_dt.py` hits, greedy
   1 µs clusters timed at their brightest hit): evt 298567 — PE≥500: **79/80**
   python clusters have a C++ flash within 1 µs and 81/84 the reverse; time
   residual median −96 ns, 68 % within 133 ns. At PE≥100: 176/232 matched —
   the deficit is `remove_late_light` + the flashes' hit-claiming absorbing
   tail clusters the python chaining counts separately (expected).
3. **PDHD unaffected**: with `wiener_inspired` off and no channel map, the PDHD
   all-PD job (run 29107 evt 983) reproduces the June-16 production archive
   **bit-identically** (inner npy equality) after both toolkit commits.
4. **Batch**: all **120 events** processed without failure — 039252 (18),
   039253 (18), 039349 (3 disjoint files × 28). Flashes/event median 383
   (331–457) over the 7.5 ms readout, ~120/event above 100 PE, max flash
   33.5 kPE. Rates consistent across the three runs.

## Output schema

`opflash_pdvd-wct.tar.gz` (TensorFileSink, prefix `opflash_`), the
flash/docs/design.md §3.4 schema with nchan=40: `opflash` f8 [nflash, 1+40]
(col 0 flash time ns rel. t0; cols 1–40 PE per OpDet), `flash_summary`
[nflash, 8], `ophits` [nhit, 9] (channel = DAPHNE opch, flash_id filled).
Downstream: `FlashTensorToOpticalPCs{nchan: 40}` → QLMatching (future).

## Caveats / next

- **`offset_us = 0`**: the light↔charge time association must be calibrated at
  Q/L-matching time (PDHD's analogue was ~250 µs from the trigoff tree; PDVD's
  charge and light events match 1:1 but the readout-window relation is not yet
  measured). Flash `t` + charge-drift consistency on A/C-crossers is the
  natural calibration.
- **Cathode PE scale provisional** (`pdvd-spe-template.md` §5): cathode columns
  of the PE matrix carry a common scale uncertainty relative to membrane/PMT;
  `min_fired_pe`/PE-balance-sensitive downstream cuts inherit it.
- **ch2020** kept (user decision): its nonlinear undershoot means its PE is
  amplitude-biased (−24 %…−5 % depending on pulse height); mask or correct at
  Q/L matching if it matters.
- The membrane threshold 4.0 is set by the top wall; the bottom wall could see
  dimmer hits at ~2.0 with a branch split (or per-channel thresholds) — deferred
  until Q/L matching shows a need.
- Watch the 468800→468864 zero-pad step: no spurious end-of-record hits seen in
  the 120-event batch (OpRoi absorbs the step), but it is a known artifact site.

## Reproduce

```bash
cd pdvd
python3 pd_plot/make_light_json.py 39252          # regenerate the cfg JSONs
./run_light_evt.sh 39252 298567                   # one event
PDVD_MAX_JOBS=6 ./run_light_all.sh 39252          # all events of a run
# validation
wcsonnet -A input_file=... -A output_file=W/light-frames-pmt.tar.bz2 \
         -S run=39252 -S event=298567 -A branch=pmt \
         -o W/.f.json wct-light-frames.jsonnet && wire-cell -c W/.f.json
python3 pd_plot/wct_wi_validate.py work/039252_light298567 pmt 39252 298567
```
